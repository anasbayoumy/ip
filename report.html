2. Node.js Concepts

2.1 What is Node.js?

Node.js is a cross-platform JavaScript runtime built on Chrome's V8 engine. It allows developers to run JavaScript code on the server (machine) rather than only in the browser. Unlike Python or Java programs that create new OS threads for concurrency, Node.js is single-threaded but achieves concurrency through an event loop.

2.2 The Event Loop & Concurrency

When Node.js encounters a blocking call (disk I/O, network request, timer), it delegates the task to libuv — a C library that manages a thread pool underneath. The main JavaScript thread continues executing other code while libuv handles the slow operation. When the operation finishes, a callback is pushed to the event queue and the event loop picks it up and runs the continuation code.

Key insight: Your JavaScript is single-threaded, but the I/O system under it is multi-threaded. This lets Node handle thousands of concurrent requests efficiently.

Asynchronous file read example (from lecture)

const fs = require("fs/promises");

async function run() {
  try {
    const data = await fs.readFile("example.txt", "utf8");
    console.log("File contents:", data);
  } catch (err) {
    console.log("Error:", err);
  }
}

run();    // Non-blocking – main thread stays free

3. REST API Design

The Mini-Twitter API models the core features of a social network: users, posts (tweets), likes, comments, and follow relationships. All data is stored in JavaScript arrays/objects in memory.

3.1 Data Models

User

{ id: Number, username: String, email: String, createdAt: ISO8601 }

Post (Tweet)

{ id: Number, userId: Number, content: String, createdAt: ISO8601 }

Comment

{ id: Number, postId: Number, userId: Number, content: String, createdAt: ISO8601 }

Like

{ postId: Number, userId: Number }

Follow

{ followerId: Number, followedId: Number }

4.3 Key Endpoint Implementations

POST /posts — Create a Tweet

app.post("/posts", (req, res) => {
  const { userId, content } = req.body;
  if (!userId || !content)
    return badRequest(res, "userId and content are required");
  if (!users.find(u => u.id === userId))
    return notFound(res, "User not found");

  const post = { id: postIdCounter++, userId, content, createdAt: new Date().toISOString() };
  posts.push(post);
  console.log(`Adding new post ${JSON.stringify(post)}`);
  res.status(201).json(post);
});

POST /posts/:id/like — Like a Post

app.post("/posts/:id/like", (req, res) => {
  const postId = parseInt(req.params.id);
  const { userId } = req.body;

  const already = likes.find(l => l.postId === postId && l.userId === userId);
  if (already) return res.status(409).json({ error: "Already liked" });

  likes.push({ postId, userId });
  res.status(201).json({
    message: "Post liked",
    likesCount: likes.filter(l => l.postId === postId).length
  });
});

GET /posts — Retrieve All Posts with Enrichment

app.get("/posts", (req, res) => {
  const result = posts.map(p => enrichPost(p));
  res.json(result);
});

function enrichPost(post) {
  const author = users.find(u => u.id === post.userId);
  return {
    ...post,
    author: author ? author.username : "unknown",
    likesCount:    likes.filter(l => l.postId === post.id).length,
    commentsCount: comments.filter(c => c.postId === post.id).length,
  };
}
